# ALPS documentation

This directory contains the canonical evidence and analysis for the final
ALPS implementation:

- `experimental_data.md`: chronological raw and consolidated experiment data;
- `bottleneck_analysis.md`: mechanism, bottleneck, and design analysis;
- `data/alps_end2end_data.csv`: machine-readable 15-model end-to-end table;
- `data/alps_hexsim_portability_20260902.csv`: V75/V79 simulator evidence;
- `references/`: the V73 architecture manuals used by the design analysis.

Historical plans, intermediate hypotheses, and superseded engineering reports
are preserved under `../../archive/engineering_notes/` and are intentionally
excluded from the public reproduction workflow.
